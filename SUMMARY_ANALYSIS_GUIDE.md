# Prophage Pipeline Summary Analysis Guide

This document provides a comprehensive overview of the summary analysis capabilities and data outputs generated by the prophage detection pipeline.

## Overview

The pipeline generates a **data warehouse approach** to prophage analysis results, creating structured tables that enable flexible downstream analysis while providing immediate basic visualizations for quality assessment.

## Quick Start

### Generate Complete Summary
```bash
# After pipeline completion
cd workflow
snakemake create_comprehensive_summary --profile ../profile/slurm/ --config outdir=/path/to/output
```

### Manual Generation
```bash
Rscript workflow/scripts/create_comprehensive_summary.R /path/to/output
```

## Output Structure

All summary results are organized in `outdir/summary_results/`:

```
summary_results/
├── SUMMARY_REPORT.md           # Main overview with embedded plots
├── tables/                     # Data warehouse tables
│   ├── master_prophage_catalog.tsv

│   ├── sample_level_summary.tsv
│   ├── tool_detection_overall.tsv
│   ├── tool_overlap_analysis.tsv
│   └── tool_detection_by_sample.tsv
├── plots/                      # Basic visualizations (PNG)
│   ├── prophages_per_sample.png
│   ├── tool_detection_by_sample.png
│   ├── overall_tool_detection_comparison.png

```

## Data Tables

### 1. Master Prophage Catalog (`master_prophage_catalog.tsv`)

**Purpose**: Complete inventory of all prophages detected across all samples

**Key Columns**:
- `prophage_id`: Unique identifier (sample_contig_start_end)
- `sample_id`: Sample name
- `contig`: Host contig identifier
- `start`, `end`: Prophage coordinates (1-based)
- `length`: Prophage length in base pairs
- `tool`: Detection tool (genomad or phispy)
- `superkingdom` through `species`: Full taxonomic classification of host
- Additional CheckV quality metrics (if available)

**Use Cases**:
- Filter prophages by quality, length, or taxonomy
- Cross-sample comparisons
- Tool performance analysis
- Custom visualization creation

### 2. Host-Prophage Relationships (`host_prophage_relationships.tsv`)

**Purpose**: Clean linkage between prophages and their bacterial hosts

**Key Columns**:
- `prophage_id`: Links to master catalog
- `sample_id`, `contig`: Identifiers
- `superkingdom` through `species`: Host taxonomy
- `simplified_taxonomy`: Concatenated taxonomy string for easy filtering

**Use Cases**:
- Host range analysis
- Taxonomic filtering
- Phylogenetic studies

### 3. Sample-Level Summary (`sample_level_summary.tsv`)

**Purpose**: Pre-computed statistics for each sample

**Key Columns**:
- `sample_id`: Sample identifier
- `total_prophages`: Total count
- `unique_contigs_with_prophages`: Number of infected contigs
- `genomad_prophages`, `phispy_prophages`: Tool-specific counts
- `mean_prophage_length`, `median_prophage_length`: Size statistics
- `min_prophage_length`, `max_prophage_length`: Size range
- `unique_phyla`: Host diversity metric
- CheckV quality breakdowns (if available)

**Use Cases**:
- Sample comparison and ranking
- Quality control assessment
- Diversity analysis

### 4. Tool Detection Comparison Tables

**`tool_detection_overall.tsv`**: Overall detection statistics
**`tool_overlap_analysis.tsv`**: Agreement between tools
**`tool_detection_by_sample.tsv`**: Per-sample tool breakdown

**Use Cases**:
- Detection method comparison
- Understanding tool complementarity
- Detection completeness assessment

## Analysis Examples

### Basic Data Loading (R)

```r
library(tidyverse)

# Load main dataset
prophages <- read_tsv("summary_results/tables/master_prophage_catalog.tsv")
sample_stats <- read_tsv("summary_results/tables/sample_level_summary.tsv")
host_relationships <- read_tsv("summary_results/tables/host_prophage_relationships.tsv")
```

### Common Analysis Patterns

#### 1. Quality Filtering
```r
# High-quality prophages only
high_quality <- prophages %>%
  filter(checkv_quality %in% c("High-quality", "Complete"))

# Size filtering
large_prophages <- prophages %>%
  filter(length >= 10000)
```

#### 2. Sample Comparisons
```r
# Prophage abundance comparison
sample_comparison <- prophages %>%
  group_by(sample_id) %>%
  summarise(
    n_prophages = n(),
    mean_length = mean(length),
    unique_hosts = n_distinct(phylum, na.rm = TRUE)
  )

# Statistical tests
wilcox.test(n_prophages ~ treatment, data = sample_comparison)
```

#### 3. Host Analysis
```r
# Most common hosts
top_hosts <- prophages %>%
  filter(!is.na(phylum)) %>%
  count(phylum, sort = TRUE) %>%
  slice_head(n = 10)

# Host range analysis
prophage_host_range <- prophages %>%
  group_by(sample_id) %>%
  summarise(
    host_diversity = n_distinct(family, na.rm = TRUE),
    total_prophages = n()
  )
```

#### 4. Tool Detection Comparison
```r
# Tool agreement
tool_comparison <- prophages %>%
  group_by(sample_id, contig) %>%
  summarise(
    tools = paste(sort(unique(tool)), collapse = ","),
    n_tools = n_distinct(tool),
    .groups = "drop"
  )

# Unique vs shared detections
unique_genomad <- prophages %>% filter(tool == "genomad")
unique_phispy <- prophages %>% filter(tool == "phispy")
```

#### 5. Custom Visualizations
```r
library(ggplot2)

# Length distribution by tool
ggplot(prophages, aes(x = length, fill = tool)) +
  geom_histogram(alpha = 0.7, bins = 30) +
  scale_x_log10() +
  facet_wrap(~ tool) +
  theme_bw()

# Host diversity by sample
ggplot(sample_stats, aes(x = reorder(sample_id, unique_phyla), y = unique_phyla)) +
  geom_col(fill = "steelblue") +
  coord_flip() +
  labs(x = "Sample", y = "Unique Host Phyla")
```

## Advanced Analysis Ideas

### Ecological Analysis
- **Prophage-host network analysis**: Bipartite networks showing which prophages infect which hosts
- **Community structure**: Clustering samples based on prophage profiles
- **Diversity metrics**: Shannon/Simpson indices for prophage communities

### Comparative Genomics
- **Core vs accessory prophages**: Which prophages appear across all vs few samples
- **Host specificity**: Do prophages show taxonomic preferences?
- **Size patterns**: Are certain hosts associated with larger/smaller prophages?

### Quality Assessment
- **Detection saturation**: Are samples fully explored or would deeper sequencing reveal more?
- **Assembly quality impact**: How does contig quality affect prophage detection?
- **Method comparison**: Systematic comparison of detection approaches

## Integration with External Tools

```r
write_csv(prophages, "prophages_for_python.csv")

# Export for phylogenetic analysis
prophage_coords <- prophages %>%
  select(sample_id, contig, start, end) %>%
  write_tsv("prophage_coordinates.bed")
```

### Database Integration
```r
# Prepare for database upload
prophages_db <- prophages %>%
  select(prophage_id, sample_id, contig, start, end, length, tool, 
         phylum, family, genus, checkv_quality) %>%
  filter(!is.na(phylum))  # Remove unclassified
```

## Troubleshooting

### Common Issues
1. **Empty tables**: Check that pipeline completed successfully for all samples
2. **Missing taxonomy**: Verify CAT/BAT database and results
3. **Memory errors**: Large datasets may need increased R memory limits

### Performance Tips
- Use `data.table::fread()` for very large datasets
- Filter early to reduce memory usage
- Consider sampling for initial exploration

## Best Practices

1. **Always start with the summary report** (`SUMMARY_REPORT.md`) for overview
2. **Use sample-level summaries** for quality control before detailed analysis
3. **Filter by quality** early in analysis workflow
4. **Document your filtering criteria** for reproducibility
5. **Validate interesting findings** by examining raw data
